## 移动风带与放行

- 点击「出发」后赛时开始，但帆船会在起点保持不动；点击「放行」后才执行航行物理。
- 「变向风」模式现在由两条移动阵风带组成。两带重叠处使用来风向量合成，因此方向接近相反时，合成风可能低于任意单带。
- 物理积分会在每条移动边界处断开暴露区间，并按加速后的状态重新求解下一次边界相遇，不用更新前的直线速度一次估算整段停留。
- 航行记录会保存风带暴露段；结束航次后可在「风带复盘」或事件列表中定位「横风 → 叠合低风 → 顺风」航段，查看帆载、提速用时和恢复到叠合前船速的实际用时。
